# 木牛流马的后世解释（高承《事物纪原》）
- 出处：宋 高承《事物紀原》卷八　舟車帷幄部，「小車」条
- 页面：维基文库「事物紀原 (四庫全書本)/卷08」 https://zh.wikisource.org/wiki/事物紀原_(四庫全書本)/卷08
- 取用日期：2026-11-10
- 版本说明：维基文库录入文本，未与纸本校勘。底本为四库全书本，页面本身标注「加標點請另外建立頁面」，即**原文无标点**；下面照录无标点原貌。要点里我加的断句只是便于阅读，非原文。

## 原文
（条目标题「小車」；本条在同卷「舟」「車」条之后，下接「檐子」。）
> 蜀相諸葛亮之出征始造木牛流馬以運餉蓋巴蜀道阻便於登陟故耳木牛即今小車之有前轅者流馬即今獨推者是而民間謂之江州車子按後漢郡國志巴郡有江州縣是時劉備全有巴蜀之地疑亮之創始作之於江州縣當時云然故後人以為名也

## 要点（供展品作者使用）
- 高承说诸葛亮出征「始造木牛流馬以運餉」（餉＝军粮），并给出理由：「蓋巴蜀道阻便於登陟故耳」。
- 解释：「木牛即今小車之有前轅者」；「流馬即今獨推者」。（我的断句：木牛，即今小车之有前辕者；流马，即今独推者。无标点原文中「獨推者是而民間謂之江州車子」的「是」字归属不明，不要擅自在此处断出确定含义。）
- 「而民間謂之江州車子」：民间称之为「江州车子」（此处「之」所指，在无标点原文里应理解为前述小车，但原文没有标点，属于阅读推断）。
- 高承的考证：引「後漢郡國志」「巴郡有江州縣」，并称「疑亮之創始作之於江州縣當時云然故後人以為名也」——这是高承自己用「疑」字表达的推测。
- 与你的记忆对照：你的大意「木牛即今小车之有前辕者；流马即今独推者」与原文一致，无出入。

### 原文未载
- 高承没有给出木牛流马的尺寸、构造、轮数（「小車」只是类比，不是复原）。
- 高承没有说「独推者」就是「独轮」；原文字面是「獨推」，「独轮」是现代常见解读，原文未写出「輪」字。
- 高承没有引用《亮集》的尺寸数据，也没有说「木牛＝独轮车、流马＝四轮车」之类（该说法不在本条中）。
- 这是宋代人（距诸葛亮约八百年）的解释，不是三国同时代记载；其可靠性应由展品标明为「后世解释」。
- 本卷其他处（例如「舟」「車」条）并无对木牛流马的其他说法；本文件未检索其余各卷（事物紀原其余卷未核对是否另有提及）。
