# 机巧

在浏览器里转动、拆开、慢放的三维图解：古代机械怎样传动，钟表怎样计时，榫卯怎样咬合。

在线看：<https://wowayou.github.io/jiqiao/>

每个展品回答两个问题：每个零件是干什么的；它们怎样一环扣一环地配合。页面右侧的「协同链」把一次完整动作拆成几环，机器转到哪一环，哪一环就亮起来。

## 怎么看

- **讲解**：点工具条上的「讲解」，一环一环看。每进一环，镜头自动到位，时间只在这一环发生的那一小段里循环（太快的慢放、太慢的快进），相关零件变红，舞台下方是这一环的一句话。
- **亲手拖**：磨的横把、水轮、足轮、车把、摆锤、分针、榫头和楔都可以直接抓住拖，机器跟着手走；首次进入时这些地方有圆圈提示。拖动只是在拨时间，零件仍沿模型算出的轨迹走。
- **迹线**：时间轴上方画着最关键的一两个量随时间的曲线（摆角是正弦，擒纵轮转角是台阶），竖线是此刻；在图上点或拖等同于拖时间轴。
- 拖动空白处旋转，滚轮朝指针处缩放，右键平移；触屏单指旋转、双指缩放平移。
- 播放、暂停、调速、拖动进度。周期很长的展品（摆钟 12 小时一圈）另有一条只覆盖一个小循环的细调条，可以一步一步看一次摆动；「跳到关键瞬间」直接停在击鼓、冲击这类时刻。
- 预设机位：一点就到擒纵、旋风轮这些默认全景下看不清的地方，挡视线的零件自动让开。
- 选中零件后「凑近看」（按钮、`F` 键或双击零件），或「隐藏」它露出后面的东西（`H` 键），「全部显示」恢复。
- 「说明与出处」页里有**实物对照**：每个展品配一件真实器物（或他人做的复制品）的三维模型，说明它与本站示意模型的异同。默认不向任何第三方发请求，点「加载三维实物」后才从 Sketchfab 加载（署名与链接一直显示）。
- 爆炸视图按装配的反顺序拆开；剖切带截面线。
- 键盘：空格播放/暂停，←→ 单步，`E` 爆炸，`S` 剖切，`F` 凑近，`H` 隐藏选中的零件，`R` 回全景，数字键切机位，`[` `]` 讲解上一环 / 下一环，`Esc` 取消选中（讲解中为退出讲解）。机位条上的「?」有完整说明。

## 哪些是史料，哪些是推测

页面上每一条陈述都带出处标签：

- **史料**：引文逐字出自 [docs/sources/](docs/sources/README.md) 里核实过的原文，有测试检查引文确实在原文里。
- **复原**、**假说**：后人的复原方案或本项目的推测。木牛流马整件属于假说。
- **模型**、**计算**：为了能动起来而定的尺寸，以及由模型算出的数；「计算」类必须有对应的测试。

史料原文摘自中文维基文库，没有与纸本校勘。模型的尺寸除记里鼓车的齿数外多为示意，不能当作文物测绘数据。

## 做法

- 运动只来自每个展品的纯函数 `simulate(t)`，不用物理引擎；画面、读数、协同链高亮读的是同一份结果。
- 零件全部由代码按参数生成，不引入外部模型文件。「实物对照」里别人做的模型只在读者点击后从 Sketchfab 在线加载，不进仓库，署名见 [docs/CREDITS.md](docs/CREDITS.md)。
- 每个展品有自动审计：零件是合法实体、运转一整圈零件之间不互相穿过、运动学关系（速比、相位、行程）与模型一致。
- Three.js + React Three Fiber 渲染，manifold-3d 做实体运算与干涉检查，Vite + TypeScript，Vitest 与 Playwright 测试。

## 本地运行

在 Node.js 24 上开发和测试。

```
npm install
npm run dev
```

其他命令：

- `npm run build`：生产构建（输出 `dist/`）
- `npm run typecheck`：类型检查
- `npm test`：单元测试与几何审计（看审计数值加 `--silent=false`）
- `npm run e2e`：浏览器测试。需先 `npm run build`，并用 `npx playwright install chromium-headless-shell` 装好浏览器；使用 5183 端口，可用 `E2E_PORT` 改；按桌面 1440 与手机 390 两种宽度遍历所有展品

发布：推送 `main` 后由 GitHub Actions（`.github/workflows/deploy.yml`）自动构建并发布到 GitHub Pages，类型检查或单元测试不过就不发布；只改文档不触发。浏览器测试不在 CI 里跑，发布前在本地跑 `npm run e2e`。

## 结构

```
src/
  kernel/       几何内核：manifold 初始化、实体与作用域内存管理、体积与交集、平面裁切、转 three 几何
  kinematics/   纯数学：位姿、齿轮系、销齿轮、渐开线、连杆、凸轮、摆、擒纵、装配序列
  kit/          参数化零件：轴与盘、木料与榫卯、磨扇、水轮、齿轮、擒纵件
  exhibit/      展品契约、场景求值、注册表（自动发现）、结构校验、几何审计、出处审计
  stage/        三维展台：状态、材质、拾取、爆炸、剖切、协同链高亮、取景与预设机位、时间轴
  ui/           页面：展厅首页、展品页、面板、主题
  exhibits/<id>/  每个展品一个目录：meta、model、parts、content、index 与测试
e2e/            Playwright 浏览器测试
docs/
  PLAN.md       方案与验收标准
  AUTHORING.md  新增展品的作者手册
  CREDITS.md    思路来源
  sources/      核实过的史料原文
```

新增展品见 [docs/AUTHORING.md](docs/AUTHORING.md)；方案、范围与验收标准见 [docs/PLAN.md](docs/PLAN.md)。
